# ep0ch
Untethered downgrades for A6. No computer needed!
# How to install?
First, add coolbooter.com as a source and install the Coolbooter app. Then, install your iOS version there.

Second, you're going to reboot back to your main iOS once youve booted into your target iOS, and install the Coolbooter Untether package.

Third, boot back into main iOS with vol up, then install the ep0ch deb in Cydia, and finally reboot the device once more via holding UP (Storage reclamation won't work until you hold up to initiate ep0ch stage)

And you're done!
*ep0ch is in beta, and i will provide no remorse or support if you ruin/brick your device right now.*
